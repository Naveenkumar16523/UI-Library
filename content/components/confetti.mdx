# Confetti

A reusable React component for triggering confetti explosions. Perfect for success states, form submissions, and onboarding completion.

## Usage

```tsx
import { ConfettiButton } from "@/components/magicui/confetti";

export default function ConfettiDemo() {
  return (
    <div className="flex h-[300px] w-full items-center justify-center">
      <ConfettiButton>Trigger Celebration!</ConfettiButton>
    </div>
  );
}
```

## Props

The `Confetti` component forwards standard HTML props alongside configuration for the confetti explosion (particle count, spread, colors).
