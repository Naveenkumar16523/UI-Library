The `GradientButton` uses Framer Motion for smooth hover and tap animations, and Tailwind CSS for the beautiful glowing gradient background. It supports custom gradients and standard button props.

<ComponentPreview name="gradient-button" />

## Installation

Run the following command to add this component to your project:

```bash
npx shadcn@latest add https://example.com/registry/gradient-button.json
```

Or you can manually copy and paste the code into your project.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `text` | `string` | - | The text to display inside the button. |
| `gradient` | `string` | `"from-purple-500 via-pink-500 to-red-500"` | Tailwind gradient classes. |
| `className` | `string` | - | Additional CSS classes for the button wrapper. |
