# Pricing Toggle

A beautiful spring-animated toggle specifically designed for pricing pages. Highlights savings on annual plans dynamically.

## Usage

```tsx
import { PricingToggle } from "@/components/ui/pricing-toggle";

export default function ToggleDemo() {
  return (
    <PricingToggle onToggle={(isAnnual) => console.log(isAnnual)} />
  );
}
```
