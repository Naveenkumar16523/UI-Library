## Overview

The `Accordion` component allows users to toggle the display of content blocks. It uses Framer Motion's `AnimatePresence` to smoothly animate the height of the content block from `0` to `"auto"`.

<ComponentPreview name="accordion" />

## Installation

```bash
npx shadcn-ui@latest add accordion
```

## Features
- Smooth height animation with `AnimatePresence`
- Built-in arrow rotation animation
- Support for `allowMultiple` sections open at once
- Fully typed and composable API
