# Scroll Scrub Section

A highly engaging parallax section. As the user scrolls, the inner content shifts vertically and fades in/out based on the scroll position relative to the viewport.

## Usage

```tsx
import { ScrollScrubSection } from "@/components/ui/scroll-scrub-section";

export default function ScrubDemo() {
  return (
    <ScrollScrubSection>
      <h2 className="text-5xl font-bold">Unleash Performance</h2>
    </ScrollScrubSection>
  );
}
```
