# Agent Chat Bubble

Animated conversational bubbles for building AI assistant interfaces, chatbots, or customer support widgets. 

## Usage

```tsx
import { AgentChatBubble } from "@/components/ui/agent-chat-bubble";

export default function ChatDemo() {
  return (
    <div className="flex flex-col gap-4">
      <AgentChatBubble isUser message="Hello, AI!" />
      <AgentChatBubble message="Hello! How can I assist you today?" />
    </div>
  );
}
```
