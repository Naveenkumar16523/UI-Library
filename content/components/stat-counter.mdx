# Stat Counter

An intersection-aware number counter. It animates up (or down) to a target value using a spring physics simulation when scrolled into view.

## Usage

```tsx
import { StatCounter } from "@/components/ui/stat-counter";

export default function CounterDemo() {
  return (
    <div className="text-4xl font-bold">
      <StatCounter value={10000} />+
    </div>
  );
}
```
