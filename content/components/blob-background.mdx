The `BlobBackground` creates an organic, moving background effect by animating the border-radius, rotation, and scale of multiple blurred gradient circles using Framer Motion.

<ComponentPreview name="blob-background" />

## Installation

Run the following command to add this component to your project:

```bash
npx shadcn@latest add https://example.com/registry/blob-background.json
```

Or you can manually copy and paste the code into your project.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `React.ReactNode` | - | Content to be placed over the background. |
| `className` | `string` | - | Additional CSS classes for the container. |
