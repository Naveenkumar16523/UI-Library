# Code Window

A macOS-style window primitive for framing code blocks, terminal outputs, or raw data payloads. Perfect for developer-focused marketing pages.

## Usage

```tsx
import { CodeWindow } from "@/components/ui/code-window";

export default function CodeDemo() {
  return (
    <CodeWindow title="terminal">
      <pre><code>npm install ui-library</code></pre>
    </CodeWindow>
  );
}
```
