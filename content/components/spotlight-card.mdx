# Spotlight Card

A sleek card that reveals a subtle spotlight effect tracing the user's cursor. Built for dark mode, this adds premium polish to any pricing or feature grid.

## Usage

```tsx
import { SpotlightCard } from "@/components/ui/spotlight-card";

export default function SpotlightDemo() {
  return (
    <SpotlightCard className="group">
      <h3>Premium Feature</h3>
    </SpotlightCard>
  );
}
```
