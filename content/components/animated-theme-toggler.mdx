# Animated Theme Toggler

A premium dark mode toggle switch. It smoothly transitions the icon and background state when swapping themes using `next-themes`.

## Usage

```tsx
import { ThemeToggle } from "@/components/magicui/animated-theme-toggler";

export default function ThemeToggleDemo() {
  return (
    <div className="flex h-[200px] w-full items-center justify-center">
      <ThemeToggle />
    </div>
  );
}
```
