## Overview

The `CardSwipe` component implements a touch-friendly, physics-based swipeable stack of cards. It utilizes `framer-motion`'s `useDrag` and `useMotionValue` to create an intuitive dragging experience with spring physics.

<ComponentPreview name="card-swipe" />

## Installation

```bash
npx shadcn-ui@latest add card-swipe
```

## Features
- Spring physics
- Stack layering effect with opacity and scale down-scaling
- Drag constraints and elastic bounds
- Event callbacks for `onSwipeLeft` and `onSwipeRight`
