The `PulseLoader` component animates a series of dots using Framer Motion, applying a stagger delay to their scale and opacity to create a smooth, pulsing effect.

<ComponentPreview name="pulse-loader" />

## Installation

Run the following command to add this component to your project:

```bash
npx shadcn@latest add https://example.com/registry/pulse-loader.json
```

Or you can manually copy and paste the code into your project.
