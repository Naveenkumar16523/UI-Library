The `GlowingCard` uses React state to track mouse position and applies a radial gradient background that follows the cursor, creating a subtle, premium hover effect.

<ComponentPreview name="glowing-card" />

## Installation

Run the following command to add this component to your project:

```bash
npx shadcn@latest add https://example.com/registry/glowing-card.json
```

Or you can manually copy and paste the code into your project.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `React.ReactNode` | - | The content inside the card. |
| `className` | `string` | - | Additional CSS classes for the card wrapper. |
