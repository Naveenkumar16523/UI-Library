## Overview

The `AnimatedTabs` component combines the unstyled, fully accessible functionality of `@radix-ui/react-tabs` with a highly polished sliding background indicator using `framer-motion`'s `layoutId`.

<ComponentPreview name="animated-tabs" />

## Installation

```bash
npx shadcn-ui@latest add animated-tabs
```

## Features
- Fully accessible out-of-the-box (Radix UI)
- Smooth sliding indicator animation
- Keyboard navigation (arrows to switch tabs)
- Elegant content mounting animation
